How it's built

One static web page: Next.js + React + Tailwind, served by Vercel. It has no server and no database. Content lives in typed EN/VI dictionaries, the simulator "plays" stage scripts, and the browser's localStorage remembers where you were.

In plain language

The pieces

At build time, Next.js turns the project into plain HTML, CSS and JavaScript files, and Vercel hands those files to visitors. Everything else happens inside the visitor's browser:

  • Content files en.ts / vi.ts hold every word. Their keys are identical, and the build fails if Vietnamese is missing one.
  • Stage scripts stages.ts describe each of the 7 stages as data. The simulator just plays them.
  • Components make up the page: navbar, hero + simulator / quick list, the drag-and-drop game, tips, footer.
  • localStorage is the browser's sticky note. It remembers the stage, mode, language, theme and sound.
  • Web Audio makes the clicks and chimes in code. There are no sound files.

type Stage = {
  id: 1 | 2 | 3 | 4 | 5 | 6 | 7;
  command: string;              // exact real command, copied as-is
  tab: "terminal" | "chat" | "files";
  terminalLines?: string[];     // played one by one

  interaction: "run" | "answer" | "approve" | "fix";

Failure modes

Where it can break, and the fallback

Clipboard blocked

The text gets selected and a "Press Ctrl+C" hint appears.

localStorage unavailable

Falls back to defaults. The page works, just without memory.

Audio blocked

Sound starts after the first click. Failures stay silent.

Missing VI text

Caught at build time by the Dictionary type.

Decisions & open issues

What's settled, what's left

  • Static export instead of a server: everything runs in the browser.
  • Two typed dictionaries instead of an i18n library with /en and /vi routes.
  • localStorage instead of accounts.
  • Scripted, simulated stages instead of a real agent, labeled as simulated on the page.
  • Generated sounds instead of audio files.
  • Next.js + React + Tailwind: your choice, already familiar to you.
  • Vercel deploy: your choice.
  • Dictionaries, localStorage, Web Audio, dnd-kit, confetti, Geist, stage scripts as data: Claude's recommendations, accepted by you.
  • Learner uncertainty: none identified. Noted, and no exercise added.
  • Library versions: verify at build start.
  • Settled at review: default language Vietnamese (your decision). Sample project: an English vocabulary flashcard app for Vietnamese learners (proposed by Claude, accepted by you).
