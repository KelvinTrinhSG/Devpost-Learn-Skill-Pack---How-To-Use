How we'll know it works

Acceptance criteria

  • Clicking Run on each of the 7 stages plays a visible result in the simulated window.
  • On interview stages, picking a preset answer makes that answer's text appear in the matching document preview.
  • Each stage's file appears in the devpost/ view at the stage that creates it.
  • Every Copy button puts the exact real command on the clipboard and shows "Copied ✓".
  • Every stage has a Details panel with its purpose, the file it creates, a tip, and an example.
  • Clicking a stage in the progress rail jumps to it.
  • Completing stage ⑦ shows the completion moment.
  • Flipping the switch shows all 7 commands without any simulation step.
  • Each Copy button copies the exact command.
  • Reloading the page keeps the chosen mode.
  • Each card can be dragged into either zone and back.
  • The preview visibly changes after every drop.
  • All cards on "AI decides" shows the generic version, and all on "You decide" shows the personal version.
  • Every tip is readable in both EN and VI.
  • No text is copied verbatim from the video transcripts.
  • Switching language changes every visible text, with no leftover strings in the other language.
  • Theme and sound toggles work and persist across reloads.
States & boundaries

What if…?

Click a card to reveal what happens.

First visit

English, Guided mode, stage ①, light theme.

Returning visit changed from scope

Opens at the saved stage with "Welcome back, continue at stage X" and a Start over button. Progress is saved in the visitor's own browser only: no account, no server. Scope had cut "saved progress" on the assumption that it needed accounts.

Journey complete

Completion moment, all stages checked, Start over available.

Copy blocked

If the browser blocks the clipboard, the command text is selected so the visitor can copy it manually.

Sound

Plays only after the visitor's first click (browser rule) and respects mute.

Reduced motion

Animations are minimized when the visitor's system asks for it.

Browser data cleared

Progress and preferences reset. Nothing persists beyond this browser.
